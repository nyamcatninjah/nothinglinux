# nothinglinux
Most lightweight distro ever
Nothinglinux aims to give users the most lightweight experience whilst using the Linux
kernel.
Nothinglinux is aimed for weaker devices and runs on aarch64

# installation
In order to install you must:
1. download the file from the OFFICAL repo
2. Open the terminal on your current arch system
3. run the following: sudo bash build-Nothinglinux (1).sh

MAKE SURE YOU HAVE ARCH ALREADY INSTALLED HOW TO MAKE SURE:
1.Go to your terminal and type: sudo pacman -S fastfetch
2. type in your terminal: fastfetch
If you are using arch it will show you the arch Linux ASCII art.
